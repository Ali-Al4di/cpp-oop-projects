# C++ OOP Fundamentals & Practice

A collection of foundational C++ programs built while learning Object-Oriented Programming principles, classes, parameterized constructors, and state encapsulation.

##  Projects Included

### 1. Virtual Pet Simulator (virtual_pet)
* **Concepts:** Classes, private attributes, custom constructor initialization, state modification methods (`feed()`, `play()`).
* **Summary:** Manages pet name, hunger, and happiness stats through automatic constructor setup upon object creation.

### 2. Car Simulator (car_simulator)
* **Concepts:** Parameterized constructors, input boundaries, vehicle state methods (`accelerate()`, `refuel()`, `stats()`).
* **Summary:** Tracks model name, current speed, and fuel percentage with logic to handle speed boosts and fuel caps.

## Environment
* **Language:** C++
